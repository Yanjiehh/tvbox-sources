# 电视台直播源（TVBox / OK影视 用）

本目录给 `360.json` 里的 `lives` 提供两份直播清单，互不依赖，哪个能用用哪个。

## 文件

| 文件 | 内容 | 验证状态 |
|---|---|---|
| `tv-cn.txt` | 公网源，12 个台（央视 3 + 卫视 9） | **已实测**：2026-11-09 用 curl 两级拉流（m3u8 可拉 + 首切片 >80KB）逐条复核 |
| `tv-mobile.txt` | 移动 CDN 源（`*.chinamobile.com/PLTV`），55 个台（央视 19 + 卫视 33 + 咪咕体育 3） | **未验证**：源为浙江移动 CDN，非移动网络一律连不通（云端实测全为 HTTP 000），须在移动宽带电视上实测定论 |

## 格式规范（改的时候照这个来）

```
分组名,#genre#
台名,播放地址
台名,播放地址
```

- 一行一个频道，`台名,地址`，逗号是英文半角，**地址里不要再出现逗号**。
- `#genre#` 单独占一行、前面只写分组名，用来切分组（央视频道 / 卫视频道 / 咪咕体育）。
- **同一台名连续写多行 = 多线路**，TVBox 会把它们合并成一个台、播放器里可切线路。要加备用线路就复制一行改地址，台名保持一致。
- **文件里不要写注释**（`#` 开头的非 `#genre#` 行有被解析成频道的风险）。要记说明就写在本 README。
- 编码 UTF-8，无 BOM，行尾 LF。

## 加台 / 换源的操作

1. 在对应分组的末尾插入 `台名,地址` 一行；同台多线路就重复台名。
2. 改完把本文件表格里的「验证状态 / 核验日期」同步更新。
3. 提交后电视端不用改配置地址，重开 OK影视 会重新拉取。

## 已知风险（别当它是“永久可用”）

- `tv-cn.txt` 全部是第三方转推流，**波动很大**：本次核验中深圳卫视一度 15 个候选全部拉不到流，隔几分钟再测又恢复（2012KB）。失效了就按上面第 1 步换地址。
- `CCTV-1` 用的是百度 `bdstatic` 的临时直播流（URL 里带时间戳），**寿命最短**，最可能先坏。
- `tv-mobile.txt` 全是浙江移动 CDN（`39.134.x.x` / `117.148.x.x`）。山西移动能不能跟省命中这些节点，**没有证据**，只能电视实测。
- 两份清单都没有 EPG 地址，电视上**不显示节目单**。
